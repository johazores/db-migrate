# Versioning

The package follows semantic versioning.

## Patch releases

Use patch versions for backward-compatible fixes, documentation corrections, and internal maintenance that does not change public commands, configuration, adapter behavior, or export formats.

## Minor releases

Use minor versions for backward-compatible commands, options, adapter capabilities, and output improvements.

## Major releases

Use major versions for breaking changes to:

- CLI commands or option semantics;
- configuration structure;
- adapter contracts;
- export or checkpoint formats;
- supported Node.js versions;
- migration behavior that requires user action.

Document upgrade steps and known data implications for every breaking release.
