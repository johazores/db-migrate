# Code of Conduct

## Our standard

Be respectful, constructive, and considerate when participating in this project.

Helpful contributions include:

- discussing technical decisions without personal attacks;
- giving clear, actionable feedback;
- respecting different experience levels and backgrounds;
- keeping issues and pull requests focused on the project;
- protecting private data and credentials shared by mistake.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, publishing another person's private information, or repeatedly ignoring maintainers' reasonable boundaries.

## Scope

This policy applies to repository issues, pull requests, discussions, reviews, and other spaces representing the project.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile. Reports will be reviewed fairly and handled with appropriate confidentiality. Maintainers may edit or remove content, close discussions, restrict participation, or block contributors when necessary to protect the project community.
