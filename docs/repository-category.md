# Repository Category

## Primary category

Developer tool and database migration utility.

## Secondary categories

- data portability;
- ETL and controlled data transfer;
- backup and restore workflow tooling;
- database schema inspection.

## Audience

The repository is intended for software engineers, platform teams, maintainers, and developers performing controlled database migrations.

## Public status

Keep the repository public and position it as a flagship open-source project after finalizing package naming and release expectations.
