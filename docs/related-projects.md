# Related Projects

This project is intentionally focused on database portability rather than application data access.

Developers may also evaluate established tools in adjacent categories:

- schema migration frameworks for application-owned incremental changes;
- ORM migration systems tied to a specific data model;
- database-native backup and restore utilities;
- managed ETL and replication platforms;
- database-specific conversion tools.

`db-migrate` is most appropriate when a small Node.js CLI, direct cross-database transfer, portable exports, and custom row transformation are more useful than adopting a full ORM or managed data platform.

No relationship or compatibility endorsement is implied by mentioning adjacent tool categories.
