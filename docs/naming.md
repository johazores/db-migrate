# Naming

The repository currently uses the `db-migrate` name and exposes a `db-migrate` CLI command.

Before public package publication, review naming against existing Node.js migration packages to avoid confusion and command collisions.

## Recommended direction

Use a distinctive name such as `cross-db-migrate` for the repository, package, and command while preserving the existing project purpose.

## Rename checklist

- repository name;
- package name;
- CLI binary;
- clone and installation examples;
- package repository, bugs, and homepage metadata;
- badges and social preview;
- release notes explaining the rename.

Do not rename published artifacts without a compatibility or deprecation plan.
