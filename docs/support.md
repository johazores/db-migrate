# Support

Use GitHub issues for reproducible bugs and focused feature requests.

Before opening an issue:

1. review the CLI, configuration, type-mapping, and troubleshooting documentation;
2. run the latest default branch when practical;
3. remove credentials and private data;
4. reduce the problem to the smallest safe schema and command.

Include the Node.js version, source and target database types and versions, command used, expected behavior, actual behavior, and relevant sanitized output.

Security-sensitive reports must follow [security.md](security.md) and should not be posted publicly.
