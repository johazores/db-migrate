# Badges

Use only badges backed by real repository information.

Recommended badges:

- MIT license;
- supported Node.js version;
- package version after a public release;
- test or build status only when an intentionally reviewed workflow exists;
- coverage only when generated and published by a real coverage service.

Do not use decorative passing, production-ready, zero-downtime, or coverage badges without supporting automation and evidence.

Keep badge placement directly below the project title and limit the row to the most useful project signals.
